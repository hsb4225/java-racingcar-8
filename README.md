# java-racingcar-precourse

구현할 기능 목록

1. 입력 기능

 - 경주할 자동차 이름을 사용자로부터 입력받는다.

 - 자동차 이름은 쉼표(,)로 구분한다.

 - 각 이름은 5자 이하만 가능해야 한다.

 - 시도할 횟수를 입력받는다.

 - 시도 횟수는 양의 정수여야 한다.


2. 자동차 객체 생성

 - 자동차 이름을 바탕으로 Car 객체를 생성한다.

 - 각 자동차는 현재 위치(전진 거리)를 가진다.


3. 자동차 전진 로직

 - 0에서 9 사이의 무작위 값을 생성한다.

 - 무작위 값이 4 이상일 경우 자동차를 전진시킨다.

 - 각 시도마다 모든 자동차의 이동 결과를 출력한다.


4. 실행 결과 출력

 - 각 자동차의 이름과 현재 위치를 출력한다.

 - 시도 횟수만큼 실행 결과를 차수별로 출력한다.


5. 우승자 판별

 - 가장 많이 전진한 자동차를 찾는다.

 - 우승자가 여러 명일 경우 쉼표(,)로 구분하여 출력한다.


6. 예외 처리

 - 입력값이 잘못된 경우 IllegalArgumentException을 발생시키고 프로그램을 종료한다.

 - 자동차 이름이 5자를 초과하는 경우

 - 자동차 이름이 비어 있는 경우

 - 시도 횟수가 숫자가 아닌 경우 또는 1 미만일 경우
   

7. 테스트 코드 작성

 - 자동차 이름 유효성 검증 테스트

 - 시도 횟수 유효성 검증 테스트

 - 자동차 이동 조건 테스트

 - 우승자 판별 로직 테스트
